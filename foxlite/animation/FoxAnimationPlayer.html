seek(seekTime:Float):Void

Normally, you'd assign a value to time to seek the animation. However, due to frame picking and interpolation, the current frame may not correspond to the current time until a number of frames later, and the values will sweep across all the frames in-between (including function calls).

This method is a fine-tuned version of the seek, it sweeps across frames in advance so the actual update happens immediately.
